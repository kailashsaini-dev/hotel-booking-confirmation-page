# Hotel Booking Confirmation Page

A responsive hotel booking confirmation page built with HTML and CSS.

## Live Demo

[View Live Website](https://kailashsaini-dev.github.io/hotel-booking-confirmation-page/)

## Features

- Responsive design
- Desktop, tablet, and mobile layouts
- Hotel booking confirmation details
- Responsive sidebar
- Booking information cards
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design
- CSS Transforms
- Hover Effects

## About the Project

This project was created to practice building a responsive hotel booking confirmation page from a provided design. The layout adapts to different screen sizes for a better user experience.
